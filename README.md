# Tic-Tac-Toe API

Backend API для игры «крестики-нолики» на NestJS. Игрок играет крестиками (`1`), ИИ — ноликами (`2`).

ИИ использует алгоритм **Minimax** и при корректной игре не проигрывает: игрок может добиться максимум ничьей.

## Технологии

- **NestJS** (TypeScript) — фреймворк для серверной части
- **Minimax algorithm** — алгоритм принятия решений ИИ
- **In-memory storage** — хранилище на основе `Map` (легко заменяется на БД). Игры хранятся в памяти приложения. После перезапуска сервера все созданные игры удаляются.
- **Thunder Client** — инструмент для демонстрации и тестирования API

## Архитектура

Проект построен по принципам Clean Architecture и разделён на три слоя:

- `web` — HTTP-контроллеры, DTO и обработка запросов
- `domain` — игровая логика, правила игры и алгоритм Minimax
- `datasource` — хранение созданных игр в памяти приложения

Слои изолированы и взаимодействуют через мапперы.

## Запуск

```bash
git clone https://github.com/vergiene/tic-tac-toe.git
cd tic-tac-toe/src
npm install
npm run start:dev
```

Сервер поднимется на `http://localhost:3000`.

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/game` | Создать игру |
| `GET` | `/game/:uuid` | Получить состояние игры |
| `POST` | `/game/:uuid` | Сделать ход |

## Модель игрового поля

Игровое поле — матрица `3x3`.

| Значение | Значение на поле |
|---:|---|
| `0` | Пустая ячейка |
| `1` | Ход игрока, крестик |
| `2` | Ход ИИ, нолик |


## Тестирование через Thunder Client

1. Установите расширение Thunder Client в VS Code.
2. Запустите сервер командой `npm run start:dev`.
3. Отправьте запрос `POST /game`.
4. Скопируйте `uuid` из ответа.
5. Выполните `GET /game/:uuid`, чтобы получить актуальное поле.
6. Измените одну свободную ячейку с `0` на `1`.
7. Отправьте обновлённое поле через `POST /game/:uuid`.
8. В ответе получите поле после хода игрока и хода ИИ.

Пример тела запроса на ход. UUID в теле должен совпадать с UUID в URL:

```json
{
  "uuid": "<uuid>",
  "field": [[1,0,0],[0,0,0],[0,0,0]],
  "status": { "isGameOver": false, "isWinner": null, "isDraw": false }
}
```
